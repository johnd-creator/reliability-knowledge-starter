# Changelog

## Unreleased — NADI V1 Release Candidate

This section describes the current factual NADI V1 release-candidate boundary.
It does not announce a release tag or future roadmap feature.

- Established NADI identity: Navigasi Analitik Data dan Informasi — Platform
  Analitik Keandalan Aset Pembangkit.
- Executive Overview with Registry-scoped Maintenance Activity, bounded trend,
  activity concentration, source distributions, controlled record evidence,
  and relationship integrity.
- Registered Asset Reliability workspace using the business Registry boundary.
- Maintenance Activity and Maintenance Investigation with explicit Repeat
  Activity semantics.
- FMEA factual assessment workspace with item-level semantics deferred.
- Asset Health factual assessment workspace without an inferred Health Score.
- Global RCFA factual workspace without invented Asset or Work Order links.
- Overhaul factual execution workspace with verified Work Order evidence and
  derived Asset resolution only through that path.
- Data Trust Center for population maturity, relationship readiness, semantic
  readiness, and known evidence gaps.
- Evidence and semantic safety gates for raw statuses, live API counts,
  unresolved relationships, and intentionally blocked analytics.
- Local Collector → Reliability Mart support remains the current V1 evidence
  path; PI/DCS PdM is not part of this candidate.

### Release boundary

The current application version is `0.1.0` across backend and frontend package
metadata. A future RC tag may follow `v0.1.0-rc.1`; no tag is created here.
